# plain for vs code

- syntax highlighting for `.plain` files
- run button (or f5) that runs the file with boot.py
- discord rich presence: "editing yourfile.plain" while you code

## discord setup (one time)

1. go to discord.com/developers/applications, click new application, name it `plain` (discord shows "playing plain")
2. copy the application id
3. optional: under rich presence > art assets, upload a logo named `plain` and a cow named `cow`
4. in vs code settings, search `plain.discord.clientId` and paste the id
