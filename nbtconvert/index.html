nbt converter

java nbt to bedrock nbt. drop a structure .nbt and get a .mcstructure you can load with a bedrock structure block, or flip any nbt file between java (big endian, gzipped) and bedrock (little endian). everything runs in your browser.

how it works

      
  
    • structure .nbt to .mcstructure: palette, blocks and size get rebuilt in bedrock's layout (x, then y, then z), missing spots become structure void, waterlogged blocks get water on the second layer
      • 
  
    • block states: axis, facing (stairs, doors, trapdoors, torches, buttons, levers, 6-way blocks), half, slab type, open, powered, lit (furnace, lamp, redstone torch, ore become their lit / unlit ids), age, level, layers, candles, pickles, eggs, bites, power, delay, comparator mode, bed parts, sign and banner rotation, plus renamed ids (dirt_path, magma_block, cobweb, sugar_cane, terracotta and more)
      • 
  
    • not carried over: block entities (chest items, sign text, banner patterns, bed colors) and entities, since their nbt is different per edition. you get a note for each
      • 
  
    • raw flip: any file converts between java and bedrock byte order. bedrock level.dat gets its 8 byte header added or removed
      • 
  
    • fence, wall, pane and stair connections are left out on purpose, bedrock recalculates them
