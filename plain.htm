plain is written in plain

plain.plain is the whole language, written in plain itself. it reads your file, sorts it into blocks, and runs it. something has to start the very first plain program though, so boot.py is the starter. once plain.plain is going, its plain running plain.

it can even run itself running your program:

python3 boot.py plain.plain plain.plain hello.plain

how to run it

python3 boot.py plain.plain hello.plain

make any text file ending in .plain, write some words in it, and run it like that. anything after the file name shows up in the arguments.

what it looks like

# lines starting with # are comments
to fib with n
  if n is less than 2 then give back n
  set a to result of fib with n minus 1
  set b to result of fib with n minus 2
  give back a plus b
end

say "fib 10 is" result of fib with 10

set mobs to a new list
add "creeper" to the end of mobs
add "zombie" to the end of mobs
for each mob in mobs
  say "watch out for the" mob
end

set score to 85
if score is at least 90 then
  say "S rank"
otherwise if score is at least 80 then
  say "A rank"
otherwise
  say "keep grinding"
end

words plain doesnt recognize just get treated as text, so you barely ever need quotes. if something breaks it tells you the line number in normal english.
