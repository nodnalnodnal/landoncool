what it looks like

# lines starting with # are comments
set name to "landon"
say hey name

set item_model to "diamond_sword"
if item_model says diamond_sword then say nice sword

set x to 3
repeat 3 times
  add 1 to x
  say "x is now" x
end

if x is more than 5 and name is landon then
  say big
otherwise
  say small
end

words it knows

set x to 5make a variable
say hello nameprint stuff. variable names get swapped for their value
add 1 to x
subtract 2 from x		change a number
ask "name?" into nameask the user something
plus, minus, times, divided bymath. set total to x times 2 plus 1
if ... then ... otherwise ... enddo stuff only sometimes. one-liners work too
repeat 3 times ... enddo stuff over and over
while x is less than 10 ... endkeep going until its not true anymore
is, says, equals, is not, contains,
is more than, is less than		ways to compare things. mix them with and / or

words plain doesnt recognize just get treated as text, so you barely ever need quotes. if something breaks it tells you the line number in normal english.
