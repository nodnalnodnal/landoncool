command porter

paste minecraft java commands, pick versions, get them converted. works both ways, one command per line.

output
    what it converts
    • 1.12 ↔ 1.13: old execute (with detect) ↔ execute as/at/if/run, selector args (r, c, m, l, rx, score_x...), data values ↔ flattened block names, numeric enchant + effect ids, gamemode/difficulty numbers, testfor, testforblock, blockdata, entitydata, xp, scoreboard players tag, scoreboard teams, particle names, plain ↔ json item and entity names
    • 1.17: replaceitem ↔ item replace, zombie_pigman ↔ zombified_piglin
    • 1.20.3: grass ↔ short_grass
    • 1.20.5: item nbt ↔ data components (enchantments, names, lore, color, unbreakable, custom model data, damage, potions, skulls, custom tags ↔ custom_data), Count ↔ count inside summon / data / selector nbt
    • 1.21.4: custom_model_data number ↔ {floats:[...]}
    • 1.21.5: json text ↔ snbt text (tellraw, title, bossbar, team, scoreboard, CustomName, custom_name, lore, signs), clickEvent/hoverEvent ↔ click_event/hover_event, HandItems/ArmorItems ↔ equipment, enchantments levels wrapper, dyed_color rgb
    • 1.21.11: camelCase ↔ snake_case gamerules
    • stuff with no equivalent in the target version gets a warning instead of being silently mangled
