what even is a g1

the innioasis g1 is a little 4 inch touchscreen music player. its basically a tiny android phone without the phone part:

partwhat it has
oscustomized android (newer firmwares are android 9)
cpu8 core, up to 1.9ghz, mediatek
ram2gb
storage16gb (about 10 to 12 usable) + microsd up to 1tb
screen4.0 inch 480x800 touchscreen
battery1500mah
wirelessdual band wifi, bluetooth 4.2 (sbc + aac)

so whats locked

out of the box the g1 wont let you install apps. no play store, and sideloading is turned off. it only runs the apps it came with (spotify, amazon music, etc). innioasis keeps a whitelist so you can update those preinstalled apps with an apk, but anything new gets blocked.

the bootloader cant be unlocked as far as anyone knows, so the usual phone stuff (unlock, flash twrp, magisk) is off the table. "jailbreaking" the g1 means patching the system so app installs work again.

read this first: the g1 jailbreak rewrites your boot and system partitions. stuff to know:
• it can brick your g1. if it gets stuck on the innioasis logo you have to reflash with sp flash tool.
• if you dont know how to use sp flash tool, learn that before you do this.
• have it plugged in and above 20% battery (lumos wont even start otherwise).
• firmware updates wipe the jailbreak. dont update without checking it still works.
• spanish firmware (G1_ES v6.xx) is not supported.

the jailbreak: lumos

lumos by seph29 is an android app that runs on the g1 itself and patches it so you can install apps. no bootloader unlock needed.

  • uses mtk-su (a mediatek temp root exploit by diplomatic) to get root just long enough to patch
  • patches boot first, reboots, then patches system
  • backs up the originals so you can restore
  • checks signatures on the files it writes so it doesnt flash garbage
  • in english, french and german, and detects your firmware version on its own
  • if your firmware isnt supported it can upload a dump so the dev can add it

step 0: check your firmware

go to settings > about on the g1 and find the build / firmware version. it looks like G1_EN-V2.14.250109 or G1-1.35.

exact list is in the compatibility table. if your version isnt on there, the lumos site says to update to a supported one first. the newest G1-9 android 9 builds are the ones that dont work yet, so if youre on an older firmware, dont update.

step 1: install it

get lumos onto the g1

the g1 blocks normal sideloading, so you push lumos over usb with adb. turn on usb debugging on the g1 first: settings > about, tap build number 7 times, then settings > developer options > usb debugging on. plug it in and allow the prompt on the screen.

need adb? grab platform tools, or:

# linux (debian/ubuntu)
sudo apt install adb
# mac
brew install android-platform-tools
# windows
winget install Google.PlatformTools

then download and install lumos:

# check the releases page for the newest version
curl -LO https://github.com/Seph29/Lumos-G1/releases/download/v1.1.2/lumos-v1.1.2.apk
adb devices
adb install lumos-v1.1.2.apk

if adb devices says unauthorized, look at the g1 screen and hit allow.

run it

  1. plug the g1 into a charger, battery over 20%
  2. open lumos, tap INJECT
  3. it patches boot and reboots
  4. open lumos again and tap INJECT again
  5. it patches system. done, apps install now.

step 2: now what

you can install apks normally now (or keep using adb install). once its patched you can even uninstall lumos. stuff people put on it:

  • nova launcher for a real home screen
  • gboard because the stock keyboard sucks
  • cx file explorer for a better file manager
  • any music app you want (poweramp, youtube music, a podcast app, whatever)

remember it has 2gb of ram and a 480x800 screen. its not gonna run genshin.

lumos also has a partial restore that only reverts system and leaves boot patched, so you can flip app installs off and back on quickly.

what about root

lumos only uses root temporarily during patching. after reboot your g1 is not rooted. thats on purpose, it keeps the player stable.

with usb debugging on you can still poke around with adb:

# shell on the device
adb shell
# firmware version
adb shell getprop ro.build.display.id
# android version
adb shell getprop ro.build.version.release
# exact chip
adb shell getprop ro.board.platform
# list installed apps
adb shell pm list packages
# push music
adb push song.flac /sdcard/Music/

the g1 is a mediatek device, which is why mtk-su works on it. mtk-su only works on older security patch levels though, which is probably why the newest android 9 firmwares arent supported yet.

it broke help

  1. dont panic. mediatek devices are really hard to perma brick.
  2. if it still boots, open lumos and use restore. it puts the original boot and system back from the backup it made.
  3. stuck on the innioasis logo? you need sp flash tool and the stock firmware for your exact version. flash the original boot.img and system.img (or the whole firmware) back.
  4. dont have the firmware? ask in the lumos discord or email innioasis support with your version number.
  5. use a real data cable, not a charge only one.
