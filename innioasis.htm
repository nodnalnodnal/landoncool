what even is an innioasis

innioasis makes cheap mp3 players that look a lot like an ipod classic, click wheel and all. the two that matter here are the y1 (silver) and the y2 (black). under the hood theyre tiny android devices on a mediatek chip (the y1 uses an mt6572), which is why people can flash them, root them and run whole different music apps on them.

"jailbreak" in the innioasis world basically means flashing community firmware that replaces or patches the stock music app. the community calls the whole scene modding and jailbreaking.

read this first: flashing firmware can brick your player. stuff to know:
• y1 and y2 firmware are NOT the same. use the model printed on your player. dont mix them.
• use a real data usb cable. charge only cables wont work and a cable that wiggles mid flash is how you brick it.
• dont plug the player in until the updater tells you to.
• community firmware can be rough around the edges. read the release notes first.
• the way back is always: flash original software for your model.

the easy way: innioasis updater

the community made innioasis updater (aka updater ce). its a gui that downloads firmware from the community archive and flashes it for you. it bundles sp flash tool and mtkclient so you dont have to mess with them. this is what you should use unless you really know what youre doing.

windows

  1. download and run DriverInstall.exe (mediatek usb drivers)
  2. download and run the updater installer.exe
  3. reboot your pc before plugging in the player

both are on the guide page.

mac

  1. install homebrew (the updater needs it)
  2. grab Innioasis.Updater.for.Mac.dmg and drag the app into applications
  3. if macos says unidentified developer, control-click the app and hit open
  4. check the mac driver notes for permissions

linux

one command:

curl -sL https://github.com/y1-community/Innioasis-Updater/releases/latest/download/run_linux.sh | bash

if it cant see the player, check the drivers page for linux permissions / udev stuff.

flashing

  1. device type: y1 that shipped with original software 2.0.0 or newer = type a (default). older y1 = type b.
  2. device model: y1 or y2. whatever is printed on it.
  3. software: pick a firmware (list below). stable release is recommended.
  4. hit install / restore and wait for it to download.
  5. power the player fully off. if it wont turn off, do what the app prompt says.
  6. when the app says ready, plug in the data cable. dont touch the cable.
  7. success message, unplug, power on. done.

the button combo for connecting is shown live in the app for your model, so just follow that.

ok which one do i get

  • i just want it to play music really well: rockbox
  • i want streaming / wifi: solar
  • i want it to feel like an actual ipod: inniclassic (y1) or rockbox with an ipod theme
  • i want it fast and customizable: jj launcher
  • i like stock but it annoys me / i want root: koensayr (y1)
  • y2 + audiobooks: y2player

root and adb

for most people you dont need to root anything yourself. the updater flashes full images, so root isnt required to install rockbox, solar, etc.

if you actually want root on a y1, the easy route is koensayr, which gives you root while keeping the stock software. root lets you mess with /system, remove preinstalled apps, change key mappings and so on.

the old manual way (from the original rockbox y1 port) was: turn on adb, root with framaroot 1.9.3, then remount system as writable. basic adb stuff once you have it:

# see if the player shows up
adb devices
# get a shell
adb shell
# become root (needs a rooted player)
su
# make /system writable
mount -o remount,rw /system
# install an apk
adb install something.apk

the exact remount command can vary by firmware. if mount -o remount,rw /system fails, run mount to see what /system is actually mounted from.

the manual / nerd way

if you dont want the gui, you can flash by hand. the y1 is a mediatek mt6572 so the classic tools work:

  • sp flash tool (v5.1904 is the one used for y1) with the mt6572 scatter file from the firmware package
  • mtkclient for low level stuff. the updater is literally a fork of it.
# mtkclient on linux, if you want to poke at it yourself
git clone https://github.com/bkerler/mtkclient
cd mtkclient
pip3 install -r requirements.txt --break-system-packages
python3 mtk.py printgpt

honestly only do this if you know mediatek flashing. the updater does all of it for you and is way less likely to brick.

it broke help

  1. dont panic, mediatek devices are really hard to perma brick. bootrom mode still works even when android doesnt.
  2. open the updater, pick original software for your exact model, and run install / restore again.
  3. dont delete folders or hidden files by hand first, even if you came from solar or rockbox. just flash stock.
  4. if it stops before the usb prompt: check drivers / permissions, try a different data cable, double check y1 vs y2, double check type a vs type b.
  5. still dead? sp flash tool and mtkclient are the advanced recovery tools. restore guides: y1 · y2
